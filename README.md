# VGC MARITIME CYBER

Maritime Cybersecurity Dashboard with real-time vessel tracking, AI-powered analytics, compliance management, and interactive visualizations.

## Features

- **Real-Time Vessel GPS Tracking** — Interactive map using Leaflet.js and OpenStreetMap with live position updates
- **AI-Powered Analytics** — Threat detection, security scoring, and predictive maintenance insights
- **Compliance Checklist** — Interactive checklist exportable to Excel (SheetJS) and PDF (jsPDF)
- **Interactive Visualizations** — Pie chart, scatter plot, and Gantt chart using Chart.js
- **Admin Settings** — GPS API configuration, alert settings, and security settings
- **Navigation Cards** — Six clickable cards with hover effects and badge indicators

## Usage

Open `index.html` in a web browser. No build step is required — all libraries are loaded via CDN.

## Libraries

- [Leaflet.js](https://leafletjs.com/) — Interactive maps
- [Chart.js](https://www.chartjs.org/) — Charts and visualizations
- [SheetJS](https://sheetjs.com/) — Excel export
- [jsPDF](https://github.com/parallax/jsPDF) — PDF export
